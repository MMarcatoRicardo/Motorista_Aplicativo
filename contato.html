Tecnologias utilizadas

Como foi construído

O projeto roda inteiro no navegador, sem framework e sem dependências instaladas. Essa escolha foi proposital: o site abre rápido em conexão fraca, funciona offline e pode ser hospedado de graça no GitHub Pages.

  • HTML5 semântico
  • CSS3 com variáveis e grid
  • JavaScript puro, sem biblioteca
  • SVG para o gráfico e a logo
  • localStorage para salvar os dados
  • Google Fonts — Barlow e IBM Plex Mono
  • Git e GitHub com branches e pull requests
  • GitHub Pages para publicação
